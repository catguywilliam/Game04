# 游戏04 · 贪吃蛇 🐍

一款经典贪吃蛇网页游戏，使用 HTML5 Canvas 构建，无需任何依赖。

## 玩法

- **方向键** 或 **WASD** 控制蛇的移动方向
- 吃到红色食物得 1 分，每 5 分自动升一关
- 撞墙或撞到自身则游戏结束
- 按 **P** 暂停/继续，按 **R** 随时重新开始
- 最高分自动保存到浏览器本地存储

## 运行方式

直接用浏览器打开 `index.html` 即可，无需服务器或安装任何依赖。

## 特性

- 流畅的 Canvas 渲染与圆角样式
- 食物光晕动效
- 蛇头眼睛随方向旋转
- 随关卡加速（最快 80ms/格）
- 本地最高分记录
